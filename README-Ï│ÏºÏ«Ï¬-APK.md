# حسابدار — ساخت APK

این پروژه سورس اندروید برنامهٔ «حسابدار» است. این بسته به‌تنهایی APK نیست.

## ساخت APK با GitHub Actions (بدون نصب Android Studio روی گوشی)
1. وارد GitHub شوید و یک مخزن جدید بسازید.
2. فایل‌های همین پوشه را در مخزن بارگذاری کنید؛ فایل `.github/workflows/build-apk.yml` نیز باید همراه سورس باشد.
3. در مخزن، بخش **Actions** را باز کنید و گردش‌کار **Build Hesabdar APK** را اجرا کنید (Run workflow). با push روی شاخهٔ main/master هم خودکار اجرا می‌شود.
4. پس از پایان موفق، در صفحهٔ اجرای workflow، از قسمت **Artifacts** فایل `hesabdar-debug-apk` را دانلود کنید. داخل آن `app-debug.apk` است.
5. APK آزمایشی را به گوشی اندرویدی بفرستید و فقط اگر به سورس اعتماد دارید نصب کنید. برای انتشار عمومی، امضای release جداگانه لازم است.

## محدودیت‌های نسخهٔ فعلی
- تراکنش‌های جدید و تنظیمات در فضای محلی همین نصب ذخیره می‌شوند.
- برای جلوگیری از ازدست‌رفتن داده‌ها، از بخش پشتیبان‌گیری مرتب فایل JSON ذخیره کنید و آن را خارج از گوشی نگه دارید.
- گزینه‌های روش ورود و اشتراک‌گذاری فعلاً تنظیمات نمایشی/محلی هستند؛ ورود پیامکی یا ایمیلی واقعی، حساب مشترک بین چند گوشی و ذخیره‌سازی ابری هنوز راه‌اندازی نشده‌اند.
- حذف داده‌های برنامه یا حذف خود برنامه می‌تواند داده‌های محلی را پاک کند؛ پشتیبان JSON را نگه دارید.
